RESOURCE / CRAFTING EXPANSION IDEAS

Goal:
Build a richer IndustrialCraft / Galacticraft / ARK-like production chain where asteroid resources have clear identities and feed ship systems, ammunition, modules, drones and machinery.

CORE DESIGN PRINCIPLE
RAW -> MATERIAL -> PART -> PRODUCT

Each resource should have a recognizable gameplay identity so the player learns what finding that asteroid means.

QUARTZ / OPTICS CHAIN

Quartz Deposit
 -> Optical Quartz
 -> Optical Lens
 -> Focusing Lens
 -> Laser Emitter / Radar Array / Scanner / Missile Guidance Sensor / Beam Weapon

Suggested Radar Array recipe later:
- 1 Circuit Board
- 1 Optical Lens
- 2 Copper Wire
- 1 Iron Plate

RECOMMENDED NEW ASTEROID ORES

1. Nickel
   Early-mid game.
   Engines, superalloys, reactor construction.

2. Lithium
   Mid game.
   Batteries, capacitors, shields, drones.

3. Cobalt
   Mid game.
   Magnetics, motors, high-temperature systems.

4. Tungsten
   Mid-late game.
   Heavy armour, penetrators, heat-resistant parts.

5. Platinum
   Late game.
   Precision electronics, catalysts, advanced reactor components.

6. Iridium
   Very late / rare.
   Exotic containment and prototype energy technology.

Do not add too many extra periodic-table ores without a gameplay identity. Avoid ending up with many visually similar ingots the player cannot distinguish by purpose.

EXAMPLE FULL SHIELD PRODUCTION JOURNEY

Mine Lithium
 -> refine Lithium Compound
 -> build Battery Cells
 -> build Capacitor Bank

Mine Copper
 -> refine Copper
 -> build Copper Wire
 -> build Magnetic Coil

Mine Crystal
 -> stabilize Resonant Crystal

Mine Silicon
 -> process Silicon Wafer
 -> build Circuit Board
 -> build Power Regulator

Mine Titanium
 -> refine Titanium
 -> build Titanium Alloy

Then assemble:
SHIELD GENERATOR

Final craft can roll a quality grade, e.g. SUPERIOR SHIELD GENERATOR.

OVERALL DIRECTION

The goal is not simply more ores. The goal is a large interconnected industrial catalogue where nearly every ship system visibly consumes manufactured components.

Good content targets:
- Armour
- Shields
- Reactors
- Thrusters
- Targeting systems
- Utility systems
- Auxiliary systems
- Ammunition
- Rockets / missiles / mines
- Drones
- Mining equipment
- Scanners
- Cooling systems
- Fuel systems
- Power storage
- Beam / plasma components
- Mechanical assemblies
- Electronics
- Advanced alloys

This should make asteroid discovery meaningful because the player knows what each resource unlocks.
